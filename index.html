Why Ezzy

Built like the Android app.
Finished as a website.

🎙 Voice-first

Speech recognition up front, spoken answers back. Hands-free mode keeps the conversation going until you say goodbye — just like MainActivity on Android.

🧠 Groq brain, JSON loop

Every reply is one JSON object — {say, action, arg, done}. The agent thinks, acts, reads the result, and repeats (up to 10 steps on Android, 6 here).

📱 Real phone actions

Open apps, tap labels, type, scroll, go back/home, torch, volume, battery, alarms, web & YouTube search — via the EzzyService accessibility loop.

🎭 14 roles

One tap re-prompts the brain: CFO, investment researcher, DevOps monitor, recruiter, CSM, social manager, analyst, engineer, SDR, EA…

🔊 Two voices

Fish Audio neural voice when you add a key, instant built-in speech synthesis otherwise. Same fallback chain as Voice.java.

🔒 Keys stay yours

Groq + Fish keys live in the app's Settings (Android) or localStorage (here). Never committed, never proxied.

Under the hood

Think → act → look → repeat.

1

You speak or type

Android uses SpeechRecognizer; here we use the browser Web Speech API with a typed fallback. Either way the text joins a 24-message history.

2

The brain answers in JSON

System prompt + role prompt + time are POSTed to api.groq.com/openai/v1/chat/completions with response_format: json_object. Reply shape: say / action / arg / done.

3

Ezzy acts, then speaks

Agent.java runs the action, feeds back RESULT + SCREEN, and loops. Voice.java prefers Fish Audio, falls back to built-in TTS. Sensitive taps ask first.

 "done": true}

Android app

Take Ezzy in your pocket.

  1. Upload the EzzyAI-ready package contents to a GitHub repo root (app/, .github/, settings.gradle…).
  2. Open the repo's Actions → Build Ezzy AI → Run workflow (AGP 8.5.2, Gradle 8.7, Java 17, SDK 34, min API 26).
  3. Download the EzzyAI artifact → app-debug.apk → install on Android 8.0+.
  4. Open Settings in the app, paste your Groq key (gsk_…). Fish Audio key + voice ID optional.
  5. Optional: enable Ezzy AI in Android Accessibility settings for screen reading + phone control.

⚠️ Accessibility access can observe screen content and interact with apps — enable only if you understand that. Review every tap that could send, buy, pay, delete, publish or submit. Never use unattended control for banking.

Safety & honesty

What Ezzy won't do.

🔑 No key harvesting

Keys are entered on your device and stored locally. This site makes no backend calls — the browser talks to Groq/Fish directly.

✋ Sensitive taps ask first

Any tap matching send / pay / buy / order / delete / post / call… pops a confirmation. Declining cancels the step.

🚫 No invented screens

The brain only taps items listed after the word SCREEN, never invents figures, names or citations, and says what it would need instead.

FAQ

Quick answers.

Where do I get a Groq API key?

Create one at console.groq.com (keys start with gsk_), then paste it in Settings on this page or in the Android app.

Do I need Fish Audio?

No. Without it Ezzy uses the built-in voice (Android TTS / browser speech synthesis). Add a Fish key + voice ID for the neural voice.

Why does the web demo refuse some actions?

Browsers can't tap other apps or read your screen. Those actions are Android-only via the Accessibility service; the demo says so and suggests an alternative.

Which model is used?

Default openai/gpt-oss-20b, editable in Settings. gpt-oss models automatically get reasoning_effort: low like the app.

Is my conversation stored anywhere?

No. History lives in memory (last 24 turns) and settings in your browser's localStorage. Clear Settings to wipe everything.
